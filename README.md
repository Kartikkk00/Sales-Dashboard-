# Sales-Dashboard-
1. Project Title / Headline
📈 Sales Performance Dashboard – Power BI
An interactive Power BI dashboard developed to analyze sales performance, profit, customer orders, product categories, payment methods, and regional sales across different Indian states.

2. Description / Purpose
The Sales Dashboard provides a complete overview of business performance by analyzing sales transactions, profitability, customer purchasing patterns, and product performance. It enables business owners and managers to monitor key metrics, identify trends, and make data-driven decisions using interactive visualizations.

3. Tech Stack
The dashboard was built using the following tools and technologies:
📊 Power BI Desktop – Dashboard development and visualization.
🔄 Power Query – Data cleaning and transformation.
🧠 DAX (Data Analysis Expressions) – Used for calculated measures and KPIs.
🔗 Data Modeling – Relationship created between Orders and Details tables using Order ID.
📈 Interactive Visualizations – KPI Cards, Bar Charts, Donut Charts, Column Charts, and Slicers.
📁 File Format – .pbix for development and .png for dashboard preview.

4. Data Source
Source: Sample Sales Dataset
The dashboard is built using two CSV files:

📁 Orders.csv
Contains customer and order information, including:
Order ID
Order Date
Customer Name
State
City

📁 Details.csv
Contains transaction details, including:
Order ID
Sales Amount
Profit
Quantity
Product Category
Product Sub-Category
Payment Mode

Both datasets are connected using the Order ID field to perform sales analysis across customers, products, locations, and payment methods.

5. Features / Highlights
📌 Business Problem
Retail businesses process hundreds of customer orders every month. Without an interactive reporting system, it becomes difficult to answer important business questions such as:
Which state generates the highest profit?
Which product category performs the best?
Which payment mode is most preferred?
Which months generate the highest sales?
Which products contribute the most profit?
Analyzing this information manually in spreadsheets is time-consuming and inefficient.

Goal of the Dashboard
The dashboard aims to:
Monitor overall business performance.
Track monthly sales and profit.
Compare product categories and sub-categories.
Analyze state-wise business performance.
Understand customer payment preferences.
Support business decisions with interactive insights.

Walkthrough of Key Visuals
📌 KPI Cards
Displays the most important business metrics:
Total Sales Amount: 438K
Total Profit: 37K
Total Quantity Sold: 6K
Average Order Value (AOV): 121K
These KPIs provide an instant overview of business performance.

📅 Month & State Filters
Interactive slicers allow users to filter the dashboard by:
Month
State

All visuals update dynamically based on the selected filters.
📍 Profit by State
A horizontal bar chart showing profit generated across different Indian states, helping identify the best-performing regions.

🛍️ Profit by Category
A donut chart comparing profit generated from:
Clothing
Electronics
Furniture

This helps understand category-wise contribution to overall profit.
📈 Monthly Profit Trend

A column chart displaying monthly profit performance, making it easy to identify seasonal trends, profitable months, and periods of lower profitability.
💳 Profit by Payment Mode

A donut chart showing profit contribution by payment methods:
COD
Credit Card
EMI
Debit Card
UPI

This helps businesses understand customer payment preferences.
📦 Profit by Product Sub-Category
A horizontal bar chart ranking product sub-categories based on profit, highlighting top-performing products such as Printers, Bookcases, Sarees, Accessories, and Tables.

Business Impact & Insights
📊 Sales Monitoring
Provides a quick overview of total sales, profit, quantity sold, and average order value.

📈 Product Performance
Identifies the most profitable product categories and sub-categories, helping optimize inventory and marketing strategies.

🌍 Regional Analysis
Highlights high-performing states, enabling businesses to focus on profitable markets and improve performance in lower-performing regions.

💳 Customer Payment Analysis
Reveals customer payment preferences, supporting better payment service strategies and promotional offers.

📅 Trend Analysis
Monthly profit trends help businesses plan inventory, marketing campaigns, and seasonal sales activities.

📌 Data-Driven Decision Making
Transforms raw sales data into actionable insights, enabling faster and more informed business decisions.
